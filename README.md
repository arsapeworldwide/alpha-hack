# Умный кредитный кабинет предпринимателя

Прототип для хакатона Альфа-Банка / Changellenge: предприниматель выбирает кредит,
отправляет заявку и получает решение с объяснением факторов. Сотрудник банка
рассматривает сложные случаи, запрашивает документы и предлагает свои условия.
Данные компании берутся из реестра: ручной ввод отключён для защиты показателей скоринга.

**Демо:** [публичный стенд](https://grants-desktop-antibody-just.trycloudflare.com).
Ссылка временная; основной способ запуска — Docker на локальном ПК.
Логины: `director` — все демо-компании, `accountant` — просмотр Альфа Ритейл,
`underwriter` — банк. Общий демо-пароль: `demo-credit-2026`.

## Запуск

Нужны Docker с Linux-контейнерами и Docker Compose. Из корня репозитория:

```sh
docker compose up --build --wait
```

Сайт: http://localhost:8080. Swagger: http://localhost:8080/api/docs.
Проверка готовности: `docker compose exec -T backend python -m app.preflight`.
Seed загружается автоматически, .env необязателен. БД и документы хранятся в
volume backend_data и сохраняются после обычного перезапуска или compose down.

## Возможности и сценарии

- Три продукта, согласие на БКИ, асинхронные проверки и история заявок.
- Объяснимое одобрение, встречное предложение и отказ с рекомендациями.
- Подписание кодом `1234` и автоматическая демонстрационная выдача.
- Банк: «Требуют решения», свои сумма/срок, обоснование превышения нагрузки,
  запрос документов и ручное рассмотрение крупных заявок.
- Директор и бухгалтер с разными правами, изоляция компаний, журнал событий,
  идемпотентность и восстановление проверок после перезапуска.
- Полезная лента и демо-пульт сбоя БКИ с повторной проверкой.

Для трёх основных сценариев выбрать профиль и оставить 10 млн / 36 мес / оборотный кредит:

| Профиль | Решение | Эталон |
|---|---|---|
| Альфа Ритейл | Одобрено | 97 баллов, 19%, платёж 366 560 ₽ |
| ИП Иванов | Встречное предложение | 46 баллов, 2 500 000 ₽, 24%, платёж 98 082 ₽ |
| Вектор | Отказ | 8 баллов, причины и рекомендации |

Полевые интервью запланированы, план — [docs/CUSTDEV.md](docs/CUSTDEV.md).

## Стек и ограничения

Python 3.12, FastAPI, Pydantic v2, SQLAlchemy 2.x, Alembic; React/TypeScript и nginx.
По умолчанию SQLite. PostgreSQL 16 запускается отдельной командой:

```sh
docker compose -f docker-compose.yml -f docker-compose.postgres.yml up --build --wait
```

Это отдельная БД; перенос данных SQLite не выполняется автоматически.
Проверки версии demo-2026-10-26: 227 pytest, 70 Vitest, ruff, ESLint и production build;
браузерные сценарии и сохранность данных проверены на SQLite/PostgreSQL.

Все данные синтетические. ЕГРЮЛ, БКИ, подписание и выдача — локальные симуляторы;
реальные деньги не переводятся. Почта, SMS и внешние API в сценарии не используются.
Документы не распознаются, проверка подлинности не реализована. Интернет нужен
для первой загрузки образов/зависимостей; основной сценарий работает без него.
Публичный туннель — дополнительный способ показа, требующий сети и работающего хоста.
