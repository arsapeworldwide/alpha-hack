# Умный кредитный кабинет предпринимателя

Прототип для хакатона Альфа-Банка / Changellenge: заявка на кредит,
объяснимый скоринг, встречное предложение, подписание и выдача.

Фронтенд готов и запускается в Docker одной командой (см. «Быстрый запуск»);
бэкенд в разработке. Стек бэкенда: Python 3.12, FastAPI, SQLAlchemy, SQLite.

Все данные синтетические. ИНН могут случайно совпасть с реальными.
ЕГРЮЛ, БКИ, подписание и выдача будут локальными симуляторами.
Код подписания — `1234`; почта, SMS и внешние сервисы в сценарии не используются.
Интернет потребуется для первоначальной загрузки образов и зависимостей;
в рантайме обращения в интернет не предусмотрены.

## Быстрый запуск (фронтенд готов)

```bash
docker compose up --build
```

Откройте http://localhost:8080. Пока сервис бэкенда в `docker-compose.yml` закомментирован, фронтенд работает в режиме мока: та же логика скоринга и статусов, данные в браузере. Сценарий проверки — `docs/TEST_SCENARIOS.md`, подробности — `frontend/README.md`.
