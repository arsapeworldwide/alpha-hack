# Сторонние компоненты и симуляторы

Заготовка для бэкенда. Список версий, лицензий и обязательных уведомлений
будет сверяться с зафиксированными зависимостями перед финальной сдачей.
Сейчас зависимости бэкенда не установлены и не зафиксированы.

| Планируемый компонент | Лицензия (предварительно) |
|---|---|
| Python 3.12 | PSF License |
| FastAPI, Pydantic, pydantic-settings | MIT |
| SQLAlchemy | MIT |
| SQLite | Public domain |
| Uvicorn, Starlette, httpx | BSD-3-Clause |
| pytest, ruff | MIT |

Смоделированные интеграции: ЕГРЮЛ (локальный поиск компании), БКИ
(синтетическая кредитная история и режим сбоя), подписание фиксированным
кодом 1234, выдача кредита (локальный переход статуса).
Связи с реальными реестрами, бюро, банком, почтой или SMS нет.
Все данные и материалы ленты синтетические.

Смоделировано во фронтенде (режим мока): ЕГРЮЛ (5 синтетических компаний), БКИ (история из карточки, режим сбоя), скоринг по `docs/SCORING_SPEC.md`, подписание кодом 1234, выдача. Материалы «Умной ленты» — синтетические тексты, написанные для демо, без ссылок на законы и реальные компании.
