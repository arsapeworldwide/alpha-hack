встречная сумма 2 500 000, платежи 366 560/98 082 и переплата прежние.

Браузер Edge / реальный HTTP / отдельный PostgreSQL-стенд:

- demo-fixes-ui: согласие, отсутствие БКИ в публичном ответе, русский формат,
  задержанный polling после редактирования, вкладки, 1 млн/24 мес, документы,
  повторный расчёт, MANUAL_REVIEW и живое решение сотрудника.
- smoke-ui: три исхода, неверный код, принятие, подпись, выдача, reload и reset.
  Видео заново записаны в docs/demo/; это фактический интерфейс, данные синтетические.
- roles-ui: директор, банк approve/reject, обновление у клиента, бухгалтер 403,
  чужая компания 404, БКИ и отзыв сессии.
- feed-ui и frontend-update: лента, советы, реестр, редактирование, история.
- После restart PostgreSQL сохранились три заявки, ручной срок 24 мес и файл PDF.

Основной способ запуска — Docker на локальном ПК; публичная ссылка —
дополнительный демо-стенд через временный туннель. Полевые интервью запланированы. Двух сотрудников для подтверждения исключения,
OCR, ФНС, антивируса и проверки подлинности вложений нет. Файл не меняет показатели
компании: после загрузки повторяются локальные проверки. PostgreSQL не переносит
SQLite автоматически, многопроцессный pipeline пока не поддерживается.
