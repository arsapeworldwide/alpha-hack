# Архив разработки

Исходные требования, фазовые чек-листы, оценки предложений и история согласования
контрактов. Они сохраняют контекст разработки и могут описывать прежние версии.
Актуальная документация начинается с [README](../../README.md), API —
в [API_CONTRACT](../API_CONTRACT.md) и [OpenAPI](../openapi.yaml).

Исходные Markdown-документы фронтенда находятся в frontend/ этого архива.
Контрольная схема docs/frontend/openapi.yaml оставлена по прежнему пути для
контрактных тестов; docs/frontend/THIRD_PARTY_NOTICES.md — для воспроизводимого
экспорта уведомлений о лицензиях. Это технические артефакты, а не дубли руководства.
