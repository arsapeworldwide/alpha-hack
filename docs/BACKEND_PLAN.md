## Допущения для реализации

- Decimal для вычислений, half-up по SPEC; деньги в API — целые рубли.
- Одна реплика API и SQLite для демо; очередь и PostgreSQL — путь развития.
- +3 месяца означает календарные месяцы с ограничением последним днём месяца.
- Для неизвестной компании и повторной проверки точные ответы нужно
  согласовать с будущим контрактом фронтенда.
- Авторизация клиента в MVP не задана; синтетическая история общая для демо.
- Вопросы схем, ошибок, повтора идемпотентного запроса и полномочий
  банковского сотрудника конкретизируются перед реализацией API.
