# ADR 004: сохраняемые этапы и локальный пульт источника

Статус: принято для прототипа.

asyncio-задачи двигают заявку по сохраняемым состояниям; каждый переход и
событие записываются одной транзакцией. При старте незавершённая работа возобновляется.
Отдельный брокер для одного процесса увеличил бы сложность запуска.

Режим БКИ хранится в demo_failures и читается симулятором при каждом запросе.
До первого изменения действует SIMULATE_BKI_FAILURE. Сбой даёт NEEDS_RECHECK,
восстановление источника и retry продолжают ту же заявку. Reset возвращает режим ok.
Пульт доступен только в DEMO_MODE директору демо-группы и сотруднику банка.

Изменение режима не имитирует настоящую сеть, таймауты или полноценный circuit breaker.
Для промышленного конвейера потребуются очередь, отдельные воркеры, аренда задачи,
ограниченные повторы, outbox и наблюдаемость. Эти компоненты пока не реализуются.
