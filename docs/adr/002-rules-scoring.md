# ADR 002: правила вместо ML

Статус: принято.

Реальных обучающих данных нет, все компании синтетические. Используем балльную
карту из SCORING_SPEC: пять факторов, Decimal и объяснение каждого вклада.
Ставки, пороги и три эталона не меняются при добавлении ролей и банковского экрана.

Рейтинг — только обозначение существующего score: A от 80, B от 60, C от 45,
D ниже 45. Это не вероятность дефолта и не новая модель.
При отсутствии расчёта показываем «Не рассчитано», не подставляем 0.

Сервер повторно получает данные реестра/БКИ, переданные клиентом показатели
не определяют итог. Браузерный калькулятор даёт предварительную оценку.
Мок остаётся инструментом автономной разработки и тестирования; Docker по
умолчанию использует реальный API.

Переход к ML потребует реальных разрешённых данных, проверки качества,
калибровки и мониторинга сдвига. Обучать модель для демонстрации баллов сейчас не нужно.
