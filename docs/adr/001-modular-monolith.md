# ADR 001: модульный монолит и SQLite

Статус: принято для прототипа.

Нужно запускать весь сценарий одной командой на компьютере жюри.
Используем FastAPI и синхронный SQLAlchemy, чистые domain-функции и отдельные
адаптеры источников. SQLite в named volume сохраняет данные без третьего сервиса.
Один Uvicorn worker и общий lock ограничивают конкурентность, но упрощают запуск.

В P1 добавлены только новые таблицы users, memberships, login_sessions,
demo_failures. create_all создаёт их рядом с прежними таблицами; заявки и суммы
не переписываются. Миграция существующих колонок в этом этапе не требовалась.

Ограничение: create_all не мигрирует существующие таблицы. До изменения их схемы
нужны Alembic, бэкап и проверка обновления. PostgreSQL и драйвер добавлять при
потребности в нескольких процессах/репликах и конкурентной записи.
