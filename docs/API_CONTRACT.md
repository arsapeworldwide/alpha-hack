# ЧЕРНОВИК бэкенда, сверить с контрактом фронтенда

Фронтенд-контракт ещё не предоставлен. Это описание состояния подготовки,
а не согласованный контракт. Список маршрутов зафиксирован в openapi.yaml.
Схемы запросов, ответов, перечисления и коды ошибок предстоит согласовать.

Все маршруты имеют префикс /api. POST /applications возвращает 201
со статусом SUBMITTED и поддерживает Idempotency-Key.
Ошибки имеют форму {code, message, details}; валидация — 422,
недопустимый переход — 409, превышение попыток подписания — 429.
Банковские маршруты требуют X-Bank-Token.
Подписание принимает {code}, решение банка — {action: approve|reject, comment}.

После получения контракта фронтенда он приоритетнее этого черновика,
если не противоречит SCORING_SPEC. Изменения описываются в CONTRACT_CHANGES.md.
