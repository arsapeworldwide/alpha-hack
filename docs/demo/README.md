# Резервные записи трёх исходов

Фактические записи браузера с реальным FastAPI, синтетическими компаниями
и авторизацией директора демо-группы. Пересняты после исправлений 25.10.2026
на отдельном Docker-стенде PostgreSQL (:8081); включают новое согласие на БКИ:

- [Одобрение, неверный код, подписание и выдача](approved.webm).
- [Встречное предложение, принятие и выдача](counter-offer.webm).
- [Отказ, причины и рекомендации](rejected.webm).

Эталоны: score 97 / 46 / 8; встречная сумма 2 500 000 ₽.
Интерфейс и полная видео-запись не доказывают качество настоящей банковской модели:
все интеграции локальные, реальные деньги не выдаются.

Воспроизведение: открыть webm в браузере. Повторная запись из корня:
`RECORD_DEMO=1 node tests/e2e/smoke-ui.cjs` (в PowerShell задать `$env:RECORD_DEMO='1'`).
Нужен установленный Playwright FFmpeg: из tests/e2e `npx playwright install ffmpeg`.
Тест создаёт заявки и в конце выполняет общий demo/reset.
Исходные записи и скриншоты — в игнорируемой tests/e2e/artifacts/.
