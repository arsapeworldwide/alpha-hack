# Объём MVP и продуктовые решения

Приоритеты основаны на основном сценарии и требованиях проверяемости.
[Гипотезы H1–H5](HYPOTHESES.md) задают план полевой проверки полезности функций.

| MoSCoW | Функция | Причина и состояние |
|---|---|---|
| Must | Три исхода и выдача | Основной сценарий; правила SPEC и эталоны сохранены |
| Must | Docker, БД, восстановление, аудит, идемпотентность | Воспроизводимость и сохранение данных; реализовано |
| Must | Роли и доступ по компаниям | Изоляция данных, бухгалтер не подписывает; реализовано |
| Must | Банковский экран | Очередь, рекомендация, своя оферта и обоснование; реализовано |
| Should | Документы, продукты, ручное рассмотрение | Необходимые ветки клиентско-банковского процесса; реализовано |
| Should | Источники, рейтинг, факторы | Объяснимость без новой модели; реализовано |
| Should | Пульт БКИ, видео, сценарий | Воспроизводимая демонстрация и резерв; реализовано |
| Should | PostgreSQL и Alembic | Переключаемая БД и обновление схемы; реализовано |
| Should | Полевые интервью | План и задания готовы, следующий этап продуктовой проверки |
| Could | График платежей, серверный preview | Приоритет уточняется после проверки H1/H3 |
| Won't now | Второй голос, ФНС, проверка подлинности | Нужны отдельная политика, интеграции и процессы |
| Won't now | Брокер, несколько реплик, ML | Не требуются для однопроцессного синтетического демо |

## Что пересмотрим после интервью

| Гипотеза | Решение, которое может измениться |
|---|---|
| H1 | Состав объяснений меньшей суммы, порядок факторов, необходимость сравнения платежей |
| H2 | Формулировки запроса, список документов и подтверждение успешной загрузки |
| H3 | Подача продуктовых карточек, статус ожидания и описание следующего шага |
| H4 | Подсказки и передача действий директору; изменение прав — отдельное решение |
| H5 | Состав фильтров и порядок очереди, расположение своей оферты и обоснования |

Наблюдения записываются по [сценарию CustDev](CUSTDEV.md). Приоритеты меняются
по фактическим затруднениям и завершению заданий, а не только по оценке «нравится».
