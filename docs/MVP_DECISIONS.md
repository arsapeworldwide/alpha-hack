# Объём MVP после P1

Доказательства: код, тесты, сценарии демо. CustDev пока запланирован,
поэтому оценки востребованности — гипотезы команды, а не результаты интервью.

| MoSCoW | Функция | Причина и состояние |
|---|---|---|
| Must | Три исхода и выдача | Основной сценарий; правила SPEC и исходные числа сохранены |
| Must | Docker, БД, восстановление, аудит, идемпотентность | Проверяемость и сохранение данных; реализовано |
| Must | Вход, компании и серверные права | Клиент не видит чужую заявку; бухгалтер не подписывает; реализовано |
| Must | Банковский экран | Закрывает ручной процесс поверх существующего approve/reject; реализовано |
| Should | Пульт БКИ без рестарта | Позволяет воспроизводимо показать отказ источника; реализовано |
| Should | Источники, рейтинг, факторы | Объяснимость без новой модели; реализовано |
| Should | Видео, ADR и сценарий | Доказательства и резерв демонстрации; подготовлены |
| Should | Реальные интервью | Нужна работа команды с респондентами; шаблон готов, результатов ещё нет |
| Could | График платежей, серверный preview | Полезны после основного сценария; отложено |
| Won't now | Второй голос, документы, ФНС, новые продукты | Требуют отдельной политики, API и сценариев; отложено |
| Won't now | PostgreSQL, брокер, несколько реплик, ML | Не требуются для однопроцессного синтетического демо; путь развития описан |
